IUT d'Amiens · Semestre 2
2024–2025
Contexte

Conception d'une application de gestion de transport en commun en C# dans le cadre d'un projet de groupe. Enjeux : organisation, délais, contraintes techniques, interface claire pour un utilisateur non-technique.

Ce que j'ai fait

Résultats

Stagiaire Développeuse Web
Clinique Victor Pauchet · Amiens
Janv. – Mars 2025 (8 semaines)
Contexte

Développement solo d'une application web « KPI Pauchet Santé » en C# ASP.NET MVC pour centraliser les indicateurs hospitaliers (KPIs) du programme HOP'EN 2. Refonte complète du site "StatsNext" existant pour l'équipe informatique de 6 personnes.

Ce que j'ai réalisé

Analyse des besoins → maquette Figma → développement front-end HTML/CSS → architecture MVC (contrôleurs, services, ViewModels) → intégration base de données à partir du MCD → logique SQL externe dynamique → documentation technique complète.

Résultats clés
✓ Espace d'admin sécurisé (users, droits, indicateurs) ✓ Système SQL dynamique sans modifier le code ✓ Indicateur INS 100% fonctionnel ✓ Documentation technique pour reprise ✓ Autonomie complète sur le projet
